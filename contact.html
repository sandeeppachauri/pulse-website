Common questions

Things teams usually ask before deploying

How long does deployment take?

Most teams have Pulse Monitor running in a SIT environment within half a day. Production deployment typically follows within a week once the team has validated it in lower environments.

Do we need to install anything on the WebLogic servers?

No. Pulse Monitor is a standard WAR deployed to your existing WebLogic cluster. WLST scripts are bundled inside the WAR — nothing is installed on the managed servers themselves.

Will it affect the performance of our SOA domain?

The WLST polling is lightweight — equivalent to a periodic admin console page load. The scheduler jobs run off-peak by default. In production use, teams report no measurable impact on SOA or OSB throughput.

Can we use it across multiple environments?

Yes. Pulse Monitor supports Local, SIT, UAT, and Production out of the box. Each environment gets its own properties file and deployment plan variables. One WAR, deployed four times.

Does the AI chatbot send our data to the cloud?

The Qiyara chatbot sends queries to whichever LLM you configure — you can point it to an on-premises model or a cloud provider of your choice. The LLM key is configured in your environment properties and never hard-coded.

What does the database setup involve?

We provide two SQL scripts — one for schema creation and one for seed data — which a DBA runs against your existing Oracle schema. Pulse Monitor then creates and manages its own tables inside that schema.
